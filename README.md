# Anteprima web — tavola a 9 quadranti

Portale web estratto da [dvd2pe/ludo2grid](https://github.com/dvd2pe/ludo2grid) (branch `main`).

- La mappa di gioco originale è sostituita dalla tavola a **9 quadranti × 9 cerchi numerati** costruita solo con ritagli dagli asset esistenti (`grid9/`).
- I cerchi sono **drag and drop**: trascina un cerchio per occuparlo, tocca un cerchio tuo per liberarlo; 5 su 9 conquistano il quadrante.
- Nessun riferimento esterno: SDK in stub locale, nessuna pubblicità, nessuna telemetria.

Script di build in `tools/` sul repo principale.
